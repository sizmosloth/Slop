# SLOP 🗿:
A Simple assistant for me 

**Purpose:**
I wanted to make my own jarvis so i am working in slop to be a self chat bot. it will give answers to normal conversations and currently i am using llm and api to search and generate response

**Things integrated in it:**
- OLLAMA LLM ( LLAMA 5b, 3b, 1b, & 0.5b and qwen 0.5b and 5b ) `https://ollama.com/`
- Tavily for internet searching `https://www.tavily.com/`

**How to Use it?**
-1. Install Python in your Computer
-2. Install required libraries 
-3. Get API key of Tavily
-4. Install any LLM from Ollama and set that model name in program 
-5. Finally - python main.py

**What i want it to be?**
Like apple siri, whenever i call it 'slop' it will open and listen and responds. Wanting to give it power to control my whole linux os with only commands and like searches the internet, can open applictions , control them on voice control =)
